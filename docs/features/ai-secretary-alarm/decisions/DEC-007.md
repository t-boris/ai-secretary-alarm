## Context

Voice requests must be transcribed and parsed into events, with clarifying dialogue. Processing location affects privacy, quality, cost and internet dependency.

## Alternatives

1. Cloud AI for both speech recognition and parsing via the user's own API key
2. Local speech recognition on the Mac, cloud AI for parsing
3. Everything local on the Mac

## Decision

Both speech recognition and natural-language parsing/dialogue use a cloud AI provider, accessed with the user's own API key.

## Reason

Best parsing and dialogue quality; single personal user accepts sending request content to the provider and paying for API usage.

## Consequences

Voice capture requires an internet connection; audio and request text are sent to an external provider; the user must supply and pay for an API key. Already-scheduled reminders must still fire offline.
