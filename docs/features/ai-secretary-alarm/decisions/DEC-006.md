## Context

Off-site events need a 'time to leave' reminder; travel time must come from somewhere.

## Alternatives

1. Automatic estimate from a mapping service with live traffic
2. AI asks the user for travel time when creating each event
3. Fixed buffer from settings (e.g. 45 minutes)

## Decision

Travel time for off-site events is estimated automatically by an external mapping service that accounts for traffic, from the user's current location (or home as fallback), using the default transport mode from settings.

## Reason

Accurate and requires no extra manual input, which matches the goal of stating intent once.

## Consequences

The app depends on an external mapping service and needs location access; a fallback is needed when the service or location is unavailable.
