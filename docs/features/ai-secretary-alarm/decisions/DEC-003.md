## Context

The assistant could either read the whole Google Calendar and remind about every event, or remind only about events it created by voice and mirror them to the calendar.

## Alternatives

1. Google Calendar as source: read all calendar events and remind about each, including manually created ones
2. Assistant-created only: remind only about events created by voice, mirrored to Google Calendar

## Decision

The assistant reminds only about events it created from voice requests and mirrors them into Google Calendar. Manually created calendar events are ignored in v1.

## Reason

Simpler: no full calendar reading or two-way sync is needed for v1.

## Consequences

Manually created calendar events get no smart reminders. The app keeps its own list of events it created. How to handle later edits or deletions of those events in Google Calendar is still open.
