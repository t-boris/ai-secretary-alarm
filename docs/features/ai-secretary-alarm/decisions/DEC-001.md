## Context

The idea said 'iOS' but described an app living in the top menu, which matches the macOS menu bar. The platform determines architecture, how the app is always available, and how alarm-style reminders can work.

## Alternatives

1. macOS menu bar app
2. iOS app (widget, Siri/Action Button)
3. Both macOS and iOS with shared data

## Decision

v1 is a macOS menu bar app. iOS is out of scope for v1.

## Reason

Matches the user's description of an always-visible app in the top menu. macOS has fewer system limits on background work and loud sound/speech alerts than iOS. v1 stays smaller than a two-platform build.

## Consequences

Reminders only reach the user when they are at the Mac. That is a known limitation for 'time to leave' alerts and needs a fallback decision (e.g. rely on Google Calendar's own notifications on the phone). iOS may come in a later version.
