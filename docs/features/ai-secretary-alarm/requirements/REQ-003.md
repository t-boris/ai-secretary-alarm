## Statement

Confirmed events, including recurring ones, are created in the single Google Calendar account connected by the app's owner, and the app keeps its own record of every event it created. Only these assistant-created events produce reminders. Changes made in Google Calendar to these events are picked up: a new time or location updates the reminder, and deleting the event cancels it.

## Acceptance Criteria

- [ ] A confirmed one-off or recurring request appears as an event in the connected Google Calendar.
- [ ] Events created manually in Google Calendar never trigger reminders.
- [ ] After an assistant-created event is moved in Google Calendar, the reminder fires relative to the new time.
- [ ] After an assistant-created event is deleted in Google Calendar, no reminder fires for it.
- [ ] Editing or deleting a single occurrence of a recurring event affects only that occurrence's reminder.
