## Statement

For events at home the reminder uses a short lead time (e.g. 5 minutes). For off-site events the app estimates travel time via a traffic-aware mapping service from the user's current location (or home address if location is unavailable), using the default transport mode from settings, and issues a 'time to leave' alarm.

## Acceptance Criteria

- [ ] Settings let the user set a home address, default transport mode and home-event lead time.
- [ ] For an off-site event, the 'leave now' alarm fires at event start minus the estimated travel time, and the estimate is refreshed close to departure to reflect traffic.
- [ ] If current location is unavailable, the home address is used as origin.
- [ ] If the travel estimate cannot be obtained, the app falls back to a fixed default buffer from settings and says so in the reminder.
