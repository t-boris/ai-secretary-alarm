## Statement

When required details are missing or ambiguous (e.g. location, lead time), the assistant asks follow-up questions before creating the event.

## Acceptance Criteria

- [ ] For a training request without a location, the assistant asks where it takes place
- [ ] The event is created only after the needed answers are received or defaults are confirmed
