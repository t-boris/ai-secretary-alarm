## Statement

The user can dictate a request at any moment from an always-visible macOS menu bar entry point. Speech is transcribed and parsed by a cloud AI provider using the user's own API key, extracting the event title, date/time, recurrence, participants and location.

## Acceptance Criteria

- [ ] Dictation can be started from the menu bar at any time.
- [ ] A request like 'meeting with Manoj at 10:30 today' yields a correct title, date and time.
- [ ] A request like 'training every Mon/Wed/Fri at 6 pm' yields a correct recurring rule.
- [ ] The API key is entered by the user and stored locally, never hard-coded.
- [ ] When offline or the API key is missing/invalid, the app tells the user clearly and creates no event; already scheduled reminders still fire.
